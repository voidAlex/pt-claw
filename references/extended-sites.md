## Cookie 配置

在 `secrets.env` 中添加对应站点 Cookie：

```
PT_COOKIE_<SITEID>=<cookie_string>
```

其中 `<SITEID>` 为上表「站点 ID」列的大写形式。例如：

```
PT_COOKIE_PTER=<cookie>
PT_COOKIE_HDAREA=<cookie>
PT_COOKIE_BYRBT=<cookie>
```

模板见 `templates/secrets.env.example`。
